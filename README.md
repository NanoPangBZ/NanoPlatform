# NanoPlatform

​	这是一套MCU嵌入式软件开发框架，用于个人学习和一些技术的验证。

设计目标:

- 高可靠性
- 实时性
- 敏捷开发
- 应用层跨平台
- 开发流程高度集成AI
  - 可测试
  - 可模拟
  - 硬件多层抽象

## 一、开发计划

### 1.1、平台基础功能和基础验证硬件

​	完成Nano_GD32F427_Smart_Core硬件设计以及配套扩展硬件，基于该硬件，完成基础的Platform一些基础框架和驱动开发。

### 1.2、开发模板项目 - 多功能数据离线收集器

### 1.3、SDL3模拟仿真功能

​	基于SDL3，开发该平台的windows/linux/MacOS的仿真bsp/framework层，保证service/app层的开发和验证可以在无硬件的情况下完成开发和调试。

### 1.4、业务层开发高度适配AI工作流

​	基于SDL3模拟仿真功能，以及开发过程中积累的规范，开发配套skill。使其在无人无实物的情况下，由AI Agent自行开发、测试、维护业务层功能代码。

### 1.5、支持AI辅助开发硬件抽象层的实现

​	收集、开发和验证各类可以连接到硬件的tool，包括在线调试、日志查看、数据手册阅读、硬件审阅、引脚分配等基础硬件侧辅助。

### 1.6、开发/验证 高复杂度的高性能MCU模板项目 - GD32H757 + 32bits-SDRAM + RGB565屏幕 + esp32c3
